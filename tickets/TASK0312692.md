## Full ServiceNow Description
Copied verbatim from the Catalog Task form:

> Working on cleaning up fields that are no longer used in the Corporate Building Model as a result of aligning information with POSSE permit data. There changes involve multiple feature classes and tables and will impact multiple views and services.
>
> `BLD_building_polygon` - changes include renaming a field alias name, deleting three fields that are no longer used and adding a new field to capture the Height Source. These changes are in support of the Building Height Analysis. At this time the new field should be hidden from Open Data and once the fields are populated I will look at releasing the field.
> `R:\ICT\ICT GIS\GIS Design Authority\Change Requests\Building Polygons\Changes to BLD_building_polygon feature class.xlsx`
>
> `BLD_BUILDING_USE` - changes include deleting four fields that are no longer used. Fire Alarms & Combustible Construction fields were added to the Building table to align with POSSE permits. FDM|Fire Prevention module has been updated and Somya is working on updating Building Details for Open Data. Once all the views and services are assessed and updated then these fields can be deleted. There are also some related building use domain values that need to be deleted as they are redundant with the Type of Structure. There will be impacts to Open Data and the metadata will need to be updated.
> `R:\ICT\ICT GIS\GIS Design Authority\Change Requests\Building Use\Delete fields in Building Use table.xlsx`
>
> `BLD_Building_Symbols` - changes include updating some field alias names and adding a new field to identify the symbol group so that like symbols can be grouped together for services or symbology. There are also some changes to symbols fcode domains and the creation of a new domain for symbols group. At this time, the new field should be hidden from Open Data until we are ready to release. There are many impacts to consolidate and replace a number of the building symbol services
> `R:\ICT\ICT GIS\GIS Design Authority\Change Requests\Building Symbols\Building Symbol Fcode Changes.xlsx`
>
> There will also be future change submissions for `BLD_BUILDING` for a new field for Vacant building and a request to delete `BLD_BUILDING_CIVIC_LINK` table. Just wanted to give the heads up in case it shows up in any of the impacted views or services.
